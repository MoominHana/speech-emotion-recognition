# Speech Emotion Recognition
 Recognizing emotions through audio or speech modality

## Dataset
  - Ryerson Audio-Visual Database of Emotional Speech and Song (RAVDESS) Dataset
  - The dataset includes 1,440 audio files featuring 24 professional actors (12 females and 12 males). These actors performed two lexically matched statements in a neutral North American accent, expressing eight emotions: Neutral, Calm, Happy, Sad, Angry, Fearful, Disgust, and Surprised. Each emotion was conveyed at two intensity levels (Normal and Strong) and repeated twice by each actor to ensure consistency and reliability.

## Machine Learning Models
  - Decision Tree
  - Support Vector Machine
  - K-Nearest Neighbor
  - Neural Network
